## Flet Starter (Python)

### Prerequisites
- Python 3.8+

### Setup
```bash
cd /workspace
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### Run
```bash
python3 main.py
```

The app starts a local server and opens in your default browser. If you're on a headless environment, copy the printed URL into a browser on your machine.
